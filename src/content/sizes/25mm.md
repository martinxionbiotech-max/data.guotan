# 25mm Cube

The 25 mm cube is the default size for coconut shell hookah charcoal. ~72 cubes per kg
(public supplier size-class table, charcoal.pro, fetched 2026-10-07).

Nominal only: no measured tolerance range is published for the class, so a
purchase specification has to state the sampling plan and the acceptable
deviation itself. See [size tolerance](/specifications/size-tolerance/).

Related: [Compare 25mm vs 26mm](https://knowledge.chinacharcoalhub.com/knowledge/25mm-vs-26mm-charcoal/)
